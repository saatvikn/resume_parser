# Resume Parser with Gemini + Streamlit

This project is an intelligent resume parser that extracts structured information from resumes (PDF/DOCX) using **Google's Gemini AI models** and presents the results in a user-friendly **Streamlit web interface**.

---

## Features

- Upload resumes in PDF or DOCX format  
- Uses **Gemini 2.0 Flash** via Google Generative AI API  
- Extracts:
  - Name, Email, Phone, LinkedIn
  - Skills
  - Education
  - Work Experience
  - Projects
  - Certifications
- Download output as JSON  
- Clean and interactive UI (Streamlit)
